## Vragen aanpassen

Open:

`opdrachten/opdracht02.json`

Elke vraag ziet er zo uit:

```json
{
  "vraag": "Carlo vindt welke eigenschap het belangrijkst?",
  "A": "Eerlijkheid",
  "B": "Humor",
  "C": "Loyaliteit",
  "D": "Ambitie"
}
```

Je hoeft alleen de tekst tussen de aanhalingstekens te wijzigen.
