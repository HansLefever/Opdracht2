# De Mol – versie 2.0

## Mappenstructuur
- `index.html`
- `assets/css/style.css`
- `assets/js/app.js`
- `data/teamA.json`
- `data/teamB.json`
- `data/teamC.json`
- `data/instellingen.json`

## Vragen aanpassen
Open het JSON-bestand van het juiste team. De software bewaart geen juiste antwoorden; de vier opties worden alleen getoond.

## Teamlinks
- `?team=A`
- `?team=B`
- `?team=C`

## Instellingen
In `data/instellingen.json` staan het versienummer, de Decoder-link, tikgeluid, vibratie en achtergrondmuziek uitgeschakeld.

Upload de volledige inhoud naar de root van je GitHub-repository.
